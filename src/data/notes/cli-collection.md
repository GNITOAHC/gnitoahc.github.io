# Daily Use

- [bat](https://github.com/sharkdp/bat): A cat(1) clone with wings.
- [eza](https://github.com/eza-community/eza): A modern alternative to ls.
- [tmux](https://github.com/tmux/tmux): A terminal multiplexer.
- [neovim](https://neovim.io): Vim-fork focused on extensibility and usability.

# Tools

- [codesfer](https://www.codesfer.io): Transfer codes efficiently.
- [processq](https://github.com/GNITOAHC/processq): Run processes in background and manage them.
- [asciinema](https://docs.asciinema.org): Record and share terminal sessions.
  - [agg](https://docs.asciinema.org/manual/agg/): Create a GIF file from asciinema recording.
- [cloudflared](https://github.com/cloudflare/cloudflared): Cloudflare tunnel client.
- [magick](https://github.com/ImageMagick/ImageMagick): Creating, editing, converting, and displaying images.
- [timg](https://github.com/hzeller/timg): A terminal image and video viewer.

# AI Tools

- [opencode](https://opencode.ai/): The open source AI coding agent.
- [opencode-session](https://github.com/GNITOAHC/opencode-session): Manage opencode sessions.

# MacOS Specific

- [caffeinate](https://ss64.com/mac/caffeinate.html): Prevent MacOS from sleeping.
- [mole](https://github.com/tw93/Mole): Deep clean and optimize your Mac.
